## How I Approach Engineering

- **Start with the system boundary.** Define contracts, responsibilities, and data flow before implementation.
- **Make AI systems observable.** Track inputs, outputs, intermediate state, failures, and evaluation signals.
- **Design for failure.** Timeouts, retries, validation, idempotency, authentication, and graceful degradation matter.
- **Separate experimentation from production paths.** Notebooks are useful; maintainable services are the end goal.
- **Understand the abstraction.** I aim to know what the framework is doing underneath the API, not only how to call it.
