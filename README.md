### 🛡️ SafeRoute — Safety & Emergency Response Platform

A multi-surface safety platform for remote and low-connectivity travel, combining a FastAPI backend, Flutter mobile application, and authority dashboard.

**Key engineering concepts:**
- JWT-based identity and authorization
- Geospatial safety zones and trip planning
- BLE SOS relay for low-connectivity environments
- Idempotent SOS queueing and delivery audit trails
- HMAC-signed relay packets with freshness validation
- Offline-first caches and background synchronization
- React authority dashboard for live operations
- PostgreSQL-ready backend with async SQLAlchemy

**Stack:** FastAPI · Python · Async SQLAlchemy · Flutter · Dart · React · TypeScript · SQLite · PostgreSQL · BLE · JWT

→ **[View SafeRoute](https://github.com/Abhishek01112002/SafeRoute)**
